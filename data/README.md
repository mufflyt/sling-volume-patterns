## NOT tracked: obtain these yourself

### Raw CMS Public Use Files, `raw/`

Eleven annual CSVs, roughly 2.2 to 3.0 GB each, about 30 GB total. Download from
[CMS Medicare Physician & Other Practitioners, by Provider and
Service](https://data.cms.gov/provider-summary-by-type-of-service/medicare-physician-other-practitioners/medicare-physician-other-practitioners-by-provider-and-service),
one file per year 2013 through 2023, and place them in `raw/` using the CMS
filenames (`MUP_PHY_R25_P04_V20_D13_Prov_Svc.csv` and so on).

> **Check each download.** The 2017 file was silently truncated on first
> download, 1.5 GB against an expected 2.7 GB, cut mid-record, and yielded 376
> sling provider-rows instead of the true 745. It produced a plausible-looking
> but wrong analysis for weeks. After any bulk download, verify each year's file
> size and the row count for your code of interest before caching.

### Board-certification rosters, `canonical_abog/` and `abu_urology/`

**These are not redistributable and are deliberately excluded from version
control.** They were purged from git history on 2026-08-17 before this
repository was made public.

| Path | Contents |
|---|---|
| `canonical_abog/canonical_abog_npi_LATEST.csv` | board diplomates: NPI, name, subspecialty, city, state, certification status, MOC status. Roughly 59,000 rows. |
| `canonical_abog/abog_subspecialty_certyear_LATEST.csv` | NPI to subspecialty certification year, derived from the subspecialty certification start-date field. Built by `scripts/build_abog_certyear_crosswalk.R`. |
| `abu_urology/abu_urps_npi_LATEST.csv` | Urology-pathway URPS surgeons: NPI, name, city, state. |

To reconstruct them, obtain equivalent certification data directly from the relevant certifying boards under their own terms, then
produce files with these column names:

```
canonical_abog_npi_LATEST.csv
  npi, subspecialty, physician_name, clinically_active, city, state,
  cert_status, moc_status, confidence_score, match_method

abog_subspecialty_certyear_LATEST.csv
  npi, subspecialty, cert_year

abu_urps_npi_LATEST.csv
  npi, abu_name, city, state, source
```

Paths are configured in `config.yml` under `abog_npi_csv`,
`abog_subspecialty_certyear_csv` and `urps_urology_npi_csv`. Setting
`urps_urology_npi_csv` to empty keeps urology-pathway URPS surgeons in the
non-URPS urology group rather than promoting them, which is the behavior you
get without the urology-pathway certification roster.

### Analysis cache, `cache/`

Generated by pipeline steps 01 and 02 from the raw CSVs. Not tracked, because it
derives from data that is not tracked. Steps 03 through 08 read the frozen cache
and do not rewrite it, so once built you can regenerate every table, figure and
the manuscript without touching the raw CSVs again.
